# Enterprise Network Infrastructure

## Project Overview

This project documents an enterprise network infrastructure covering office areas, workshop environments, wireless networks, CCTV surveillance, and access control systems.

## Network Technologies

| Category | Technology |
|---|---|
| Firewall | FortiGate |
| Core Switching | Huawei |
| Aggregation Switching | Huawei |
| Access Switching | Huawei |
| Wireless | Huawei Controller and Access Points |
| CCTV | Hikvision |
| Access Control | ZKTeco |
| Routing | OSPF and Static Routing |
| Network Services | VLAN, DHCP, NAT |

## Project Scope

1. Firewall configuration and routing.
2. VLAN and IP addressing design.
3. Core and aggregation switching.
4. Wireless controller and access point configuration.
5. CCTV and NVR configuration.
6. RFID access control configuration.
